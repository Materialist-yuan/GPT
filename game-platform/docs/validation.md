## TCP 机器人实测

原始 JSON：`reports/acceptance-50bots.json`。

```sh
docker compose --profile tools run --rm -T --no-deps robot \
  -bots 50 -duration 30s -ramp 5s -rate 20 -payload-bytes 128 \
  -report /reports/acceptance-50bots.json
```

环境：Linux x86_64，整体容器环境 CPU 配额约 2 核、内存上限 8 GiB；机器人、登录服务、网关、PostgreSQL 16 和 Redis 7 在同一宿主环境中运行。使用默认 bcrypt cost 12、4 个准备工作线程，裸 TCP，Echo/心跳消息，无真实游戏逻辑后端。
